# Game Design Language — City Crime Open World

## 视觉风格
- Top-down 2D 俯视视角，像素化渲染（pixelated/crisp-edges）
- 城市地图：100x100 网格，道路网格 + 建筑方块 + 公园水域
- 色调：深灰道路、彩色建筑、绿色公园、深蓝水域
- 角色：绿色玩家、彩色行人、蓝色警察、彩色车辆
- 明暗循环：昼夜交替，夜间街灯光晕

## 色彩
- 道路 #333、标线 #FF0、人行道 #888
- 建筑随机从 #556677 ~ #998877 选取
- 玩家 #00CC00，警察 #0033CC
- 通缉星标 ★ #FF0、血条绿/黄/红
- HUD 深色半透明背景 + 白色文字

## 字体
- 全部 monospace（等宽字体）
- 标题 64px bold、HUD 12-16px、提示 14px、帮助 11px

## 动效
- 镜头跟随玩家平滑过渡
- 受击/射击画面震动
- 夜间街灯光晕闪烁
- 警察灯红蓝交替闪烁
- 水面波纹

## 禁令
- 不使用外部图片或音频
- 不使用第三方游戏引擎或库
- 纯 Canvas2D 实现
- 所有资源内联在 game/ 目录中
